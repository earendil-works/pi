# .nltotoi — NLT-Pi Governance Namespace

Machine-readable and tooling-oriented governance metadata for NeuroLift Technologies' NLT-Pi repository.

- `index/governance-files.md`: repository-local governance registry.
- `scripts/validate-governance.sh`: read-only governance validation.
- Root `nltotoi.json`: discovery manifest.

Canonical repository contract: `NLT-DEV-OTOI.md` (NLT-PI-DEV-OTOI-1.0.0).

The organization templates originate in `NeuroLift-Technologies/.github-private`, but these files are adapted for NLT-Pi and are owned locally. No automatic upstream propagation is configured.
