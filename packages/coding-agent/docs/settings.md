# Settings

Global settings are read from `~/.pi/agent/settings.json`; trusted project overrides are read from `.pi/settings.json`. Objects merge recursively and project values win.

Common keys: `defaultProvider`, `defaultModel`, `defaultThinkingLevel`, `theme`, `tuiMode`, `defaultTools`, `sessionDir`, `enabledModels`, `extensions`, `skills`, `prompts`, `themes`, `packages`, `compaction`, `retry`, `transport`, and `defaultProjectTrust`.
