# packages/web-ui/src/tools/artifacts

## Purpose
Artifact system for the web UI: creates, displays, and manages rich content artifacts (HTML, SVG, images, markdown, text, PDF, DOCX, Excel) generated by the AI agent. Artifacts are rendered in sandboxed iframes with runtime providers.

## Technology
TypeScript, Lit web components, sandboxed iframes.

## Contents
- `artifacts.ts` - `ArtifactsPanel`: main panel managing artifact list, selection, and display
- `artifacts-tool-renderer.ts` - `ArtifactsToolRenderer`: renders artifact creation tool results in chat
- `ArtifactElement.ts` - `<artifact-element>`: wrapper component for individual artifacts
- `ArtifactPill.ts` - `<artifact-pill>`: inline artifact reference pill in messages
- `HtmlArtifact.ts` - HTML artifact renderer (sandboxed iframe with runtime providers)
- `SvgArtifact.ts` - SVG artifact renderer
- `ImageArtifact.ts` - Image artifact renderer
- `MarkdownArtifact.ts` - Markdown artifact renderer
- `TextArtifact.ts` - Plain text artifact renderer
- `PdfArtifact.ts` - PDF artifact renderer
- `DocxArtifact.ts` - DOCX document artifact renderer
- `ExcelArtifact.ts` - Excel spreadsheet artifact renderer
- `GenericArtifact.ts` - Generic/fallback artifact renderer for unrecognized types
- `Console.ts` - `Console` Lit element: in-artifact console log display with `LogEntry` interface
- `index.ts` - Barrel export

## Key Functions
- `ArtifactsPanel.addArtifact(artifact)`: Add new artifact to panel
- `ArtifactsPanel.getArtifact(id)`: Retrieve artifact by ID
- `ArtifactsToolRenderer.render(args, result)`: Render artifact tool result

## Data Types
- `Artifact`: `{ id, type, title, content, language? }`
- `ArtifactsParams`: Configuration for artifacts panel behavior

## Logging
N/A

## CRUD Entry Points
- **Create**: AI agent creates artifacts via tool calls, rendered in panel
- **Read**: `getArtifact(id)` to retrieve, artifacts panel displays all
- **Update**: Artifact content can be regenerated via agent
- **Delete**: Artifacts cleared on session reset

## Style Guide
- One renderer per artifact type
- Sandboxed iframe for HTML/SVG execution
- Pill components for inline references in chat messages
