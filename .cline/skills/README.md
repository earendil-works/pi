# .cline/skills

Skill references for Cline. Loadable Agent Skills are defined in `.agents/skills/` (Pi's documented project skill location). This directory references them rather than duplicating governance guidance, so every agent surface (`.claude/`, `.kilo/`, `.cline/`) uses the same skills.

Reference a skill by name:
- `nlt-implementation-agent`, `nlt-code-reviewer`, `nlt-governance-steward`
- `incident-response`, `new-agent-onboarding`, `repo-governance-setup`
- `agent-registration`, `commit-message`, `escalation`, `handoff-record`, `intent-log`, `review-record`
- `vercel-mcp`, `rivet-mcp`

See `.agents/README.md` for the full skills index and source mappings.
