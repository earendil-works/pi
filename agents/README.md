# NLT-Pi Agent Profiles

Repository-level role definitions for agents working on NLT-Pi. These are guidance profiles, not an authorization system. Actual capability enforcement belongs to the applicable ASFDK harness and integration controls.

- `nlt-governance-steward.md`: read-only governance review.
- `nlt-code-reviewer.md`: read-only code/security review.
- `nlt-implementation-agent.md`: scoped implementation workflow.

Agent profiles must not grant themselves permissions or override human approval.
