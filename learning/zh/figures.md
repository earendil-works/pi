# 中文技术图规范

新增 27 张图的底稿、源码依据与返工记录见[逐图说明](figure-notes.md)，本文件保留首批样图的约定。

全书 34 张。需要比较对象归属、跨请求的状态变化、乱序事件、分支投影或崩溃窗口时画图。单个签名、字段或目录用代码和表格。一个问题一张图；拆图时在目录写出新增问题并调整预算，跨章复用沿用原图号。

## 每张交稿前填写

1. 写明读者问题、可判对错的答案、源码提交与入口。列出对象、容器和当前状态。教学别名、示意数值、实测结果分别标注。
2. 写出输入、结果和每条边的起点、终点、动词、前提与时间方向；互斥分支分别标出口和恢复位置。表格按列或行明确读序，无因果关系的对象并排列出。
3. 横向 3:2 或 16:10，白或浅灰底，炭灰中文无衬线，蓝表请求、青表返回、紫表状态或判断，文字也要能独立辨认语义。紧凑页眉约 5–7%，标题为正文 1.5–1.8 倍；细边框、对齐、2–4 个互补区域。禁止装饰性箭头、卡通、3D 和整段塞框。
4. 在正文阅读宽度检查字体、字段拼写和单位，再盖住正文沿图作答。错连、错序或添加无来源的组件时，记录缺陷、修改目标和保留项，定向重绘并重新核验。
