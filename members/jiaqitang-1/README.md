#我的Git学习笔记
## 第一次Git实验总结 
1. git add 的作用是： 
将工作区中修改的文件加入暂存区（stage/index），标记这些文件准备提交，把变更告诉 Git，还没有生成版本记录。
2. git commit 的作用是：
把暂存区里已经 add 的变更，在本地仓库生成一条新的版本提交记录（快照），附带提交信息，只保存在本地 Git 仓库，还没有上传到远程 GitHub。
3. git restore notes.md 的作用是：
用暂存区（或者最近一次 commit）里的版本，覆盖恢复工作区的 notes.md 文件，丢弃工作区里还没 add 的修改，撤销本地文件改动。
4. commit 与 push 的区别是：
`commit`：只在本地仓库生成版本快照，改动只存在你电脑上，不会同步到 GitHub 远程仓库；
`push`：把本地仓库已经 commit 好的提交记录，上传推送到 GitHub 远程仓库，让远程服务器同步你的版本，其他协作者才能看到你的代码。
