# Demo Mission

Goal: exercise mission control against a tiny, safe, self-contained build mission.

Success looks like:
- `TASKS.json` ends with every task at `done`
- `PROGRESS.md` reflects the current next step or completion state
- any demo artifacts stay inside `devdocs/missions/demo/`

Constraints:
- keep the mission self-contained inside this directory
- prefer the smallest possible changes
- update mission state files as work progresses
