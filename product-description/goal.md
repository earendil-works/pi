## Things already established (do not re-derive, do not contradict)

- Double-press windows: Ctrl+C twice within 500 ms quits; Escape twice within 500 ms on an empty editor opens `/tree` (setting `doubleEscapeAction`, default `tree`). Both measured from the first press.
- Escape priority, highest first: dismiss the autocomplete popup; abort the turn (returning queued messages to the editor); cancel a running shell command; clear the editor when in bash mode; the double-Escape action on an empty editor. During a retry countdown, compaction, or branch summarization, Escape cancels that instead.
- Ctrl+C once clears the editor. Ctrl+D quits only when the editor is empty; otherwise it deletes the character under the cursor.
- Submit trims the text; an empty submit does nothing visible. Built-in slash commands are matched on the exact trimmed text before any busy check and run immediately, even while the agent is working or compacting; `/reload` is the only one that refuses while busy. An unrecognised `/` line is sent to the model as text (queued as a steering message if the agent is working).
- Enter while working queues a steering message; Alt+Enter queues a follow-up (and behaves as Enter when idle); Alt+Up returns the whole queue to the editor. Default delivery is one-at-a-time for both queues.
- A prompt is appended to the session and shown in the transcript before the model is called. Aborting keeps it.
- The session file is created on the first assistant message, not before. A session with no response has no file; forking or cloning it is refused with "This session has not been saved yet."
- Retry: up to 3 attempts with 2, 4, 8 second waits, on overloaded, rate-limit, 5xx, and network errors; not on quota, billing, or usage-limit errors. The failed attempts stay in the session file but are dropped from the model's context.
- Abort: the partial assistant message is kept with stop reason aborted; running tools are stopped and get `Operation aborted` results; not-yet-started tool calls in the same message also get `Operation aborted`. Aborted and errored assistant messages are excluded from the next model call.
- Compaction: automatic when context exceeds the window minus 16,384 tokens; keeps the newest 20,000 tokens verbatim; the summary is appended as an entry and nothing is deleted. Overflow recovery compacts and retries the turn exactly once. While compacting, submissions are queued with "Queued message for after compaction".
- Thinking level default `medium`, clamped to the model; levels `off, minimal, low, medium, high, xhigh, max`. Shift+Tab cycles; Ctrl+T hides or shows thinking blocks; the editor border colour follows the level (or green in bash mode).
- The default active tools are `read`, `bash`, `edit`, `write`; `grep`, `find`, `ls` exist but are off. Tool output is truncated to the last 2,000 lines or 50 KB, whichever comes first, with the full output in a temp file. Collapsed previews: bash tool 5 lines, read/write 10, grep 15, find/ls 20, user shell command 20. Ctrl+O expands or collapses every box at once.
- Prompt history: 100 entries, in memory only, consecutive duplicates skipped, browsed with Up/Down from the edges of the text. Large paste threshold: more than 10 lines or 1,000 characters. No redo; undo is cleared on submit.
- The default model when nothing is set: the saved `defaultProvider`/`defaultModel` if it is available, else the first available model in pi's provider order. With no credentials pi starts with `Warning: No models available. Use /login …` under the header, shows `unknown` as the model in the footer (and `0.0%/0 (auto)` for context), and the first prompt fails with `Error: No API key found for the selected model.` plus the login help; the prompt is neither recorded nor drawn. (Observed with the driver on 2026-08-23.)
- The `~/.pi/agent/` layout: `settings.json`, `auth.json`, `keybindings.json`, `trust.json`, `sessions/<cwd-derived dir>/<timestamp>_<id>.jsonl`, `bin/` (downloaded `fd` and `rg`). `PI_CODING_AGENT_DIR` relocates all of it.
- Settings precedence: command-line flag > project `.pi/settings.json` (trusted projects only) > `~/.pi/agent/settings.json` > built-in default. `/settings` writes the global file and applies at once.
- Shell commands (`!`): run in the session's working directory in a fresh shell each time, no timeout, output streamed, 20-line collapsed preview, cancelled with Escape, recorded as a user-role message the model sees next turn; `!!` records but hides from the model. A command started while the agent is working is recorded when the turn ends.
- The footer: line 1 is cwd (`~` for home), ` (branch)`, ` • name`; line 2 is `↑in ↓out Rcache-read Wcache-write CHhit% $cost[ (sub)] pct%/window[ (auto)]` left and `[(provider) ]model[ • level]` right; `?` for the percentage after a compaction until the next response; warning colour above 70%, error above 90%.
- Status line texts: `Working... (escape to interrupt)`, `Retrying (n/3) in Ns... (escape to cancel)`, `Compacting context... (escape to cancel)`, `Auto-compacting... (escape to cancel)`, `Context overflow detected, Auto-compacting... (escape to cancel)`, `Summarizing branch... (escape to cancel)`.
- Session directory: `~/.pi/agent/sessions/--<abs path with / \ : replaced by ->--/<ISO timestamp>_<uuid>.jsonl`. Session files are not locked. `-c` opens the newest file by modification time; the picker sorts by last message time.
- Credential precedence per provider: `--api-key` > stored credential in `auth.json` > environment variable. OAuth refreshed when under 5 minutes remain. `/logout` removes only the stored credential.
- Startup model: the session's recorded model if resuming and available; else the saved default if available (and in scope); else the first model in scope, or the first available provider's default model in pi's provider order.
- Precedence: flag > environment (for the few that have one) > project `.pi/settings.json` (trusted only; arrays replace, objects merge) > global `settings.json` > default. `/settings` writes global and applies live.
- State ownership in `conversation/`: `sending-a-prompt.md` owns the turn from Enter to settled including abort, retry, and error display for a single prompt; `tool-calls.md` owns what happens inside a tool call and how each tool renders; `the-message-queue.md` owns what happens to a second submission while working; `the-editor.md` owns everything before Enter; `the-transcript.md` owns how finished messages look and Ctrl+O; `cross-cutting/busy-state.md` owns the matrix of what every command and shortcut does while working, compacting, and retrying, and the feature documents link to it for their "A slash command…" interrupt row.
