# Verification: sessions and startup

How to run this file: start from a fresh home (`rm -rf /tmp/pi-desc-home`) and an empty project directory with `git init` run in it, at 100×40 or larger. Most items here need *saved sessions*, which exist only after a model has answered ([sessions](../foundations/sessions.md#the-session-model)); make them once with a credential (two sessions of three short prompts each, one of them named with `/name Demo`, is enough for every `keyboard` item below that says "a saved session"), then run the `keyboard` items with `--no-env` and `PI_OFFLINE=1`. Items marked `model` observe a response, an abort, a summary, or a compaction and need a cheap model at thinking level `off` or `low`; they check structure and state, not wording. Where a document's cancel-and-interrupt cell merely restates a foundations rule (one Ctrl+C clears, Escape with text is a no-op), the row is in [conversation.md](conversation.md) and is not repeated here; cells specific to the command are rows below. Clear between sections by quitting pi (`/quit`) and, where the section says "fresh home", deleting the home directory. No pass has been run on these documents: every Result is `—`.
