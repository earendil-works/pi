# Verification: models, settings, and cross-cutting

How to run this file: start from a fresh home (`rm -rf /tmp/pi-desc-home`) and an empty project directory with `git init` run in it, at 100×40 or larger, in a Kitty-protocol terminal (Ghostty or Kitty unless the Device column says otherwise). Items marked `keyboard` need no credential; run them with `--no-env` and `PI_OFFLINE=1`. Items marked `model` need one provider key (two where the Setup says so) and a cheap model at thinking level `off` or `low`; they observe structure and state, not wording. Items that say "dummy key" use an invalid key such as `sk-bad` because only the display is being checked; if pi validates the key, mark the item `blocked`. Clear between sections by quitting pi (`/quit`) and, where the section says "fresh home", deleting the home directory. `cat settings.json` means the file in the home directory. Results marked "driver" were observed with `driver/drive.py` on 2026-08-23 at commit `a69bef789`; everything else is `—`.
