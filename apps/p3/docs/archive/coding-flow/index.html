Pi, coding
p3 · walkthrough · the coding companion to “Pi, simply”

Say what's broken. The work runs where the code is.

This is the coding half of the Home-first proposal. Mario talks to Pi in Home. Pi picks the checkout and the machine, and the work shows up as a card. Opening a card goes one level down: the transcript, a live terminal, the diff, the files.

Underneath, every piece of work uses one list: the machines, logins and tools it may touch. A project carries its list. Everyone working in it uses all of it, and each thing on it keeps its owner's login. The screens show the list only when it matters: when it grows, while something lent is in use, and when someone asks.

Eleven screens follow Mario through one morning in pi-mono, from a flaky test to a merged fix, with Cristina joining halfway.

Left out on purpose

  • No repository or machine picker on the way in. Pi picks; the chip shows the choice and changes it.
  • No prompt per command. Pi asks when pi-mono's list would grow, and before anything leaves the machine. Running tests in the checkout needs no question.
  • No resource panel next to every conversation. The list is shown when asked, at the moment it changes, and in the bar while something lent is in use.
  • No editor. Diff, files, git and terminal are views of the checkout. Editing by hand stays in Mario's editor, and Pi sees the result.

Open questions

  • This Mac or slayer? Proposed: where the checkout is and the last run was; ask only when both have it and the work will run long.
  • When a card asks, and when it acts. Proposed: ask before pushing, before anything touches someone else's machine or login, and before deleting; act on everything else in the checkout.
  • How much transcript by default. Some coders want the terminal open, not the card. Remember the last choice per project, or a per-person setting?
  • A folder, not the whole machine. The list holds a machine; ~/pi-mono is only where work sits. Should a machine on a list be narrowed to one folder?
  • “For this task” and a clock. Underneath, a lent thing ends at a time. Does “this task” end when the card is done, and what if the card never finishes?
