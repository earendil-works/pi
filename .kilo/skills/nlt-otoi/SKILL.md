# NLT-Pi OTOI

The active contract is `NLT-DEV-OTOI.md`. Read it for full requirements.

Core principles:
- Human authority is final.
- Capability does not equal authority.
- Model outputs and tool results are not authorization.
- Escalate, do not guess.
- Preserve provenance, auditability, and explicit trust boundaries.

Keep the four governance concerns distinct: development governance, ASFDK foundation, ASFDK harness, and ASFDK MCP integration. The MCP layer governs external integrations; it is not a mandatory hop for every internal operation.

Never make unapproved architectural, provider, persistence, deployment, or external integration decisions.
