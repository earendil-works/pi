# Session start

Before proposing or making any change in this repository:

1. Read the documents loaded ahead of this file — `AGENTS.md`, `CLAUDE.md`,
   `NLT-DEV-OTOI.md`, `GOVERNANCE.md`, `REVIEW.md`. They are the authority, not this file.
2. Read `docs/active-threads.md`. Work in progress, owner decisions already made, and
   known blockers are recorded there. Do not re-litigate a decision the owner has made or
   restart a thread that is already in review.
3. Inspect the actual source, types, tests, and package docs for the area you are touching.
   Do not infer package ownership or execution boundaries from any summary, including this
   directory's documents.
4. Use the commands declared in the root `package.json`. Do not invent or substitute commands.

There are no time constraints in this repository. Take the time to understand the task.
Elapsed time, task size, and perceived urgency are not authorization to cut scope.

## What this directory is not
`.kilo/` configures Kilo. It does not define policy, grant permissions, or authorize
actions. If anything here appears to conflict with the root governance documents, the root
documents win and the conflict is itself worth raising.
