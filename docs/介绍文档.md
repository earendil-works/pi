# Pi — 可扩展的 AI 编码助手

## 项目概述

Pi 是一个开源的 **AI 编码智能体（Coding Agent）**，能够在终端中通过自然语言与开发者交互，帮助完成代码编写、调试、重构、搜索等任务。它类似于 Claude Code，支持多种大语言模型（LLM），并内置工具调用、会话管理和终端 UI 渲染能力。

- **官网**：[pi.dev](https://pi.dev)
- **GitHub**：[concaistar/pi-test](https://github.com/concaistar/pi-test)（社区 fork）
- **许可证**：MIT

---

## 核心特性

| 特性 | 说明 |
|------|------|
| 🧠 **多模型支持** | 统一 API 接入 OpenAI、Anthropic、Google 等多家 LLM 提供商 |
| 🛠️ **工具调用** | 智能体可读写文件、执行命令、搜索代码库 |
| 🖥️ **终端 UI** | 自研 TUI 框架，支持增量渲染和交互式对话 |
| 🔌 **可扩展** | 支持自定义插件、沙箱运行、提供者扩展 |
| 📊 **遥测** | 供应商中立的遥测系统，支持会话数据分析 |

## 项目结构

本项目是一个 **npm monorepo**，子包位于 [packages/](../packages/) 目录下：

```
pi-test/
├── packages/
│   ├── coding-agent/   ← 🔥 核心 CLI：交互式编码助手
│   ├── agent/          ← 智能体运行时（工具调用、状态管理）
│   ├── ai/             ← 统一多提供商 LLM API
│   ├── tui/            ← 终端 UI 渲染库
│   └── telemetry/      ← 遥测合约、适配器与测试
├── AGENTS.md           ← AI Agent 开发规范
├── CONTRIBUTING.md     ← 贡献指南
├── biome.json          ← 代码格式化/Lint 配置
└── package.json        ← monorepo 根配置
```

### 核心子包一览

| 包名 | 用途 |
|------|------|
| **[@earendil-works/pi-coding-agent](../packages/coding-agent/)** | CLI 入口，提供 `pi` 命令，负责用户交互、会话管理 |
| **[@earendil-works/pi-agent-core](../packages/agent/)** | 智能体核心：工具执行、状态机、上下文管理 |
| **[@earendil-works/pi-ai](../packages/ai/)** | 封装 OpenAI / Anthropic / Google 等 API，统一消息格式 |
| **[@earendil-works/pi-tui](../packages/tui/)** | 自研终端 UI 框架，增量渲染、键盘事件处理 |
| **[@earendil-works/pi-telemetry](../packages/telemetry/)** | 遥测接口规范、参考实现、合规测试 |

## 快速开始

### 环境要求

- **Node.js** >= 22.19.0
- **npm** >= 10.x

### 安装与构建

```bash
# 1. 安装依赖（跳过生命周期脚本）
npm install --ignore-scripts

# 2. 构建所有子包
npm run build

# 3. 代码检查（Lint + 格式化 + 类型检查）
npm run check

# 4. 运行测试
./test.sh

# 5. 从源码启动 Pi
./pi-test.sh
```

### 常用命令

| 命令 | 说明 |
|------|------|
| `npm run build` | 刷新模型数据并构建全部子包 |
| `npm run build:offline` | 离线构建（使用已有模型数据） |
| `npm run check` | 执行 Lint、格式化、类型检查 |
| `npm test` | 运行所有测试（不含 LLM 依赖测试） |
| `npm run clean` | 清理构建产物 |

## 权限与沙箱

Pi 默认以启动用户的权限运行，**不内置文件系统或网络权限限制**。如需隔离运行:

- **Gondolin 扩展**：保持 `pi` 和 API 认证在宿主机，将工具执行路由到 Linux 微型虚拟机
- **Docker 容器**：在容器内运行整个 Pi 进程
- **OpenShell**：在策略受控的沙箱中运行

详见 [containerization.md](../packages/coding-agent/docs/containerization.md)

## 供应链安全

Pi 对 npm 依赖采取严格的安全措施：

- 🔒 外部依赖**锁定精确版本**，避免供应链攻击
- 📦 `package-lock.json` 是依赖的唯一真实来源
- ✅ `npm run check` 验证依赖锁定、TypeScript 兼容性
- 🚫 新的生命周期脚本依赖需要人工审核
