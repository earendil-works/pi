### NLTPI-MVP-003 — Provider-agnostic model routing for the governed turn
**Status:** gateway chosen (Vercel AI Gateway) and wired (nlt-pi#21, #26, #27); not yet run against the real gateway  
**Owner:** Joshua W. Dorsey, Sr. / delegated coding agents  
**Summary:** The owner chose provider-agnostic routing through the Vercel AI Gateway on 2026-11-04, so the model provider can be swapped without code changes. `runAgentTurn` (`mvp/src/agent/runner.ts`) now calls `pickFreeModel({ requireToolUse: true })` at turn time — inside the per-turn deadline, after the crisis gate — and binds the chosen model to the Pi session through `bindGatewayModel`; an injected model choice is re-checked against the free-model rule before it is bound. No model identifier is hard-coded. Offline tests and a faux provider only: no turn has reached the real gateway.  
**Gateway notes (from Vercel documentation, 2026-11-04):** on Vercel deployments the platform supplies an OIDC token automatically, so no stored key is needed there; `AI_GATEWAY_API_KEY` is only for local development and takes precedence over OIDC when set. Per-request provider options include `zeroDataRetention`, `disallowPromptTraining`, `only` (restrict providers) and `models` (fallbacks). These are candidates for prompts that may contain crisis content; none are applied, per the retention decision below.  
**Retention decision (owner, 2026-11-05): free models only, with a data notice.** Measured that day: the 3 strictly free catalog models are all `zdr: "none"` and `no_training: "none"`, and two descriptions say the provider retains prompts and outputs. Requiring the guarantees would block every free model, so none are required; the tool is for the owner's personal use only, and the chat page carries a data notice (free models only, what an allowed turn sends to the provider, and that gate-blocked messages are not sent). The crisis gate still runs first, so blocked messages are never sent. A privacy-first variant (catalog filter plus request options) was built and set aside in a local stash, not pushed.  
**Model policy (owner decision, 2026-11-04):** only free models are allowed through the gateway. The gateway's public catalog (`GET https://ai-gateway.vercel.sh/v1/models`, no authentication) lists per-token prices, so "free" can be checked from data and not from a hand-kept list. Measured the same day: 4 of 320 language models were listed at zero input and output price, and one of them was flagged `varies_by_provider`, so a zero price is not guaranteed on every provider. Implementation must therefore (1) read the catalog, (2) allow only models with zero input and output price that are not `varies_by_provider`, (3) fail closed (refuse the turn) when the catalog cannot be read or the chosen model is not on that list, and (4) not hard-code model identifiers in source. The catalog changes, so the check must run at use time. Free models can have weaker data-handling terms, which is what the retention decision above trades against.  
**Open:** the free model is whatever the catalog offers that turn, so the provider can differ between turns and there is no pinning; a first real gateway turn is unrun. Exposure is settled: the turn is reachable only through `/api/agent`, which is off unless the owner sets `NLT_AGENT_ENABLED=1` and answers 401 without a signed-in owner (nlt-pi#26, #27), behind the ASFDK harness and the Vercel Authentication wall.  
**Next action:** none for the retention decision. Owner: set the flag in one environment and approve a first real gateway turn (cost); revisit the retention decision if a free model with zero retention and no training appears.
