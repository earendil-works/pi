# 设计原则

1. Steer 入口必须与 prompt() 入口对扩展钩子系统等价,任何监听 `before_agent_start` 的扩展都能感知新主题。

2. 文件操作跟踪优先覆盖高频简单模式(>` mv` cp` rm` sed -i`),不追求 AST 完整性,接受 ~20% 边缘场景漏报。

3. grep` find` ls 的输出通过反向 regex 提取文件路径,视作"读取"语义,不改文件状态。

4. 不为路径提取引入新的运行时依赖(shell parser/ AST 库),维持 pi 的零外部依赖原则。

5. 被动注入 + 扩展钩子 + 阈值控制是记忆系统核心范式,本次修改不引入新机制(不主动 tool / 不滑动窗口)。

6. 工具结果截断(50KB / 2000 行)已是 baseline,文件跟踪 regex 必须正确处理 truncated 边界,不假设完整输出。

7. 边界 case 降级而非报错,任意文件跟踪失败不应阻塞压缩流程。
