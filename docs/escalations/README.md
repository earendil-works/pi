# Escalations

Store repository escalation records here using `templates/escalation.md`. Do not store credentials, exploit details, vulnerability reproduction steps, private customer data, or other security-sensitive incident evidence in this public repository.

Security vulnerabilities and security-sensitive incidents must be reported through a private channel: use GitHub's private vulnerability reporting / Security Advisories for this repository when available. If that channel is unavailable, stop and obtain the repository owner's established private reporting route; do not fall back to a public issue. Do not invent or publish a contact address.

GitHub issues may be used only for sanitized tracking after the repository owner confirms the content is safe for public disclosure. Public records should contain status, owner, and a non-sensitive summary only; keep investigation details and evidence private.
