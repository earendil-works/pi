# tui

Everything on the terminal, display and input.

In:
- pi-tui rendering in regular and fullscreen mode.
- Scrollback, flicker, redraw cost, CPU use while streaming.
- Markdown, syntax highlighting, images.
- Message and tool renderers, themes, footer, header.
- Prompt editor, keybindings, key decoding (kitty protocol, legacy sequences).
- Paste, clipboard, IME, autocomplete, external editor.
- Terminal replies leaking into input, mouse and selection.

Examples: #9255, #8822, #10154, #8212, #9583, #10319, #7321, #10352, #10362, #9497.

Usually not worth opening: terminal-specific reports without OS, terminal, or video; theme and footer knobs (should be an extension).
