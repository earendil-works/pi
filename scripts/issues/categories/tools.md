# tools

Built-in tools.

In:
- read, write, edit, bash, grep, find, ls, and user ! commands.
- Output truncation.
- Shell selection and spawning, process cleanup, timeouts.
- Images in tool results (resizing, limits).

Not here:
- How tool calls are rendered: tui.
- MCP tools: mcp.
- Codemode and tool_search: codemode.

Examples: #6817, #9129, #9276, #10015, #10482, #9361, #10527.

Usually not worth opening: fuzzy edit matching wishes (#10207, #10340).
